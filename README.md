# KSTP Premium - Site E-commerce Champagne & Vins

🥂 Site e-commerce professionnel pour la maison KSTP Premium, spécialisée dans la vente en gros de champagnes et vins à Reims, France.

## 🎯 À propos du Projet

KSTP Premium propose une sélection exclusive de champagnes et vins haut de gamme pour professionnels et revendeurs. Ce site web offre une expérience utilisateur élégante et moderne pour découvrir les produits et demander des devis personnalisés.

## ✨ Fonctionnalités

- **Design Premium** : Interface élégante Rouge/Or/Blanc avec animations fluides
- **Multipage** : Navigation complète avec 8 pages professionnelles
- **Catalogue Produits** : Grilles de produits avec système de filtres (Champagnes et Vins)
- **Formulaire de Contact** : Demande de devis avec validation
- **Responsive Design** : Optimisé pour tous les appareils (mobile, tablette, desktop)
- **SEO Optimisé** : Structure H1/H2/H3 optimisée pour le référencement Google
- **Animations Waou** : Effets parallax, smooth scroll, fade-in au scroll
- **Menu Sticky** : Navigation fixe avec effet de scroll
- **Pages Légales Complètes** : Mentions légales, CGV, Confidentialité conformes RGPD

## 🚀 Mise en Ligne

### Prérequis
- Hébergement web (recommandé : Hostinger)
- Nom de domaine : `shop.kstp-premium.com`

### Installation
1. Cloner ou télécharger le repository
2. Uploader tous les fichiers sur votre serveur web
3. Configurer le domaine pour pointer vers le dossier racine
4. Le site est prêt !

### Configuration
- Mettre à jour l'email de contact dans le formulaire (actuellement : contact@kstp-premium.com)
- Ajouter des images de produits réels dans le dossier `/images/`
- Personnaliser les produits dans `champagnes.html` et `vins.html`
